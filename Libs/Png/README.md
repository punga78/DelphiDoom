# Libs\Png

Codifica e decodifica PNG (la compressione arriva da un `IZlib` iniettato).

Il testo di riferimento (paragrafi spostati dal CLAUDE.md di radice, issue #178) sta in [CLAUDE.md](CLAUDE.md).

## Contenuto

- Unit nella cartella: 20 (nome a punti `DelphiDoom.Png.*`).
- Interfacce dichiarate: `IPng`.
- Punto di creazione delle classi: `DelphiDoom.Png.Provider`.
- Progetti nella cartella: `DDPng`.

## Prova

- Progetto di test in `Tests\`: `DelphiDoom.Tests.Png`. Si compila con `Tools\build.bat` (vedi "Build e prove" nel [CLAUDE.md di radice](../../CLAUDE.md)).
