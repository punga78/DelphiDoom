# Tests\Data\MapFile

Dati del confronto di `Libs\MapFile` (issue #106) con il **vero** idlib di Doom 3. **Nessuna mappa di Doom 3 e' nel repository**: i file `.map` sono scritti per il test (testi di prova inventati).

- `cases.txt`: i casi, uno per riga: il nome del file senza estensione; ` !` in coda = il lettore ignora il file `.reg` (`ignoreRegion`); `#` = commento.
- `*.map`, `region.reg`: v2_basic (versione 2: sei facce, brush con coppie, patchDef3, entita' con `origin` e una patchDef2, valori che mettono alla prova la scrittura dei float: `0.00048828125`, `123456789`, `0.1`), v1_old (senza `Version`: brushDef a tre punti, patchDef2, un brush spostato dall'origine, un brush di Quake III), directives (le quattro chiavi del worldspawn), region (+ `.reg`), empty, keys (spazi finali, chiavi che differiscono per maiuscole, una chiave senza valore, origine con un numero non valido, coppie di brush e di patch), nonascii (materiale con byte sopra 127), e gli errori `err_*` (entita' non chiusa, parentesi mancante, piano incompleto, patch con larghezza 0, riga della patch corta, chiave del brush non stringa, brush non chiuso, matrice della texture incompleta); `missing` non ha file.
- `mapfile.golden.txt`: la risposta del C++ (557 righe). Per ogni caso: `CASE`, `PARSE 0/1`, poi (se letto) `NAME`, `VERSION`, `FILETIME`, `HASPRIM`, `GEOCRC`, le entita' (`ENT`, `KV`), le primitive (`PRIM brush` con `EP`, `SIDE` = piano e materiale, `TM` = matrice della texture, `TV` = vettori della texture; `PRIM patch` con `V` = punti), `WRITE`, il **testo riscritto** (righe `| ...`) e `ENDWRITE`; oppure `ERR` con il messaggio. I float sono `#` e i 32 bit in esadecimale; i testi sono scritti con l'escape del C. Le righe `P:` e `W:` sono il log (`writing X...`, avvisi).
- Il test che li usa: `TTestMapFileGolden` (`Tests\Source\DelphiDoom.Tests.MapFile.Golden.pas`, con `DelphiDoom.Tests.MapFile.Dump.pas`): rifa ogni caso con le classi Delphi e confronta riga per riga; le righe `TV` ammettono 2 ULP (il C++ calcola `sin`, `cos` e `atan2` in `float`; a 0 ULP differisce 1 riga di 557, di 1 ULP). Se non coincide scrive `DelphiDoom.Tests.MapFile.mapfile.actual.txt` accanto all'eseguibile.

## Come sono stati prodotti

Nessun sorgente C++ di Doom 3 e' nel repository. L'harness sta fuori (nella cartella temporanea); in `harness\` ci sono i tre file scritti per il test: `driver.cpp.txt` (legge `cases.txt` e i file, stampa il formato sopra; file system in memoria; `common->Error` lancia un'eccezione), `precompiled.h.txt` (stub di `common`, `sys`, `idFile` e `idFileSystem`; include `Surface.h`, `Surface_Patch.h` e `MapFile.h` veri; **senza STL**, perche' le intestazioni dinkumware64 di `bcc32c` non reggono `<string>`) e `build.ps1.txt`. Preparazione: copiare `Reference\doom3\neo\idlib` in `idlib\` accanto allo script; nella copia mettere `precompiled.h.txt` come `precompiled.h`, `driver.cpp.txt` come `driver.cpp`, e `fsw.inc` = le righe 36-146 di `neo\framework\File.cpp` (la funzione vera `FS_WriteFloatString`, che e' la formattazione dei float scritti) con `idfile.inc` gia' incluso in `precompiled.h`. Si compilano con `bcc32c -std=c++14` (il clang di Delphi 11, 32 bit): `driver`, `Str`, `Token`, `Lexer`, `Dict`, `Heap`, `MapFile`, `math\Math`, `Vector`, `Matrix`, `Angles`, `Quat`, `Rotation`, `Plane`, `Pluecker`, `Polynomial`, `Complex`, `Simd_Generic`, `hashing\CRC32`, `containers\HashIndex`, `geometry\JointTransform`, `Surface`, `Surface_Patch`, `DrawVert`. `ID_REDIRECT_NEWDELETE` (definito nello stub) spegne l'allocatore a blocchi delle stringhe. Poi `map.exe <cartella dei dati> > mapfile.golden.txt`. Il driver chiama `idMath::Init()` (altrimenti un'asserzione in `Math.h`).

Il C++ compilato e' quello vero tranne: `idMapPatch` eredita il vero `idSurface_Patch` (compilato, solo `SetSize` e i dati sono usati), `idFile::WriteFloatString` usa la vera `FS_WriteFloatString`, il file system e' in memoria (ora del file sempre 1234). Non provato: la lettura da un file di disco vero e le mappe di Doom 3.
